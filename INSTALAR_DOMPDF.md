# Instalación de DomPDF para Reportes PDF

## Ejecuta este comando en tu terminal:

```bash
composer require barryvdh/laravel-dompdf
```

## Después ejecuta:

```bash
php artisan vendor:publish --provider="Barryvdh\DomPDF\ServiceProvider"
```

## Una vez instalado, vuelve a cargar la página de reportes y podrás descargar PDFs reales.
